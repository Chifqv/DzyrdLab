# DzyrdLab

> Методический портал для хранения пособий и материалов по осетинскому языке.

Проект предназначен для **учителей**, **воспитателей** и **родителей** и даёт
пользователям удобное место, где методические разработки можно найти по теме и
классу, скачать, оценить и обсудить — а авторам — опубликовать свою работу без
бюрократии, но с возможностью рецензирования.

---

##  Цель

Создать единое цифровое пространство, где материалы можно:

| Действие | Описание |
|:---|:---|
|  **Загружать** | публикация своих методических разработок на платформе |
|  **Хранить** | структурированное хранение и каталогизация всех записей |
|  **Просматривать** | чтение PDF и изображений прямо в браузере, в цифровом виде |
|  **Скачивать** | сохранение файлов на локальный носитель |

---

##  Первая версия

В первую версию проекта входят:

-  **Каталог материалов** — структурированное хранилище всех записей
-  **Поиск и фильтрация** — быстрый доступ к нужным документам
-  **Просмотр PDF и изображений** — встроенная читалка прямо в браузере
-  **Административная панель** — управление контентом и пользователями
-  **Скачивание файлов** на устройство пользователя
-  **Модерация** — при публикации материалы отправляются на проверку администраторам

---

##  Роли

В первой версии проекта оставляем **три базовые роли**:

| Роль | Права |
|:---|:---|
| **Гость**<br><sub>без регистрации / входа</sub> | Просмотр всех разделов и материалов<br>Поиск и фильтрация |
| **Зарегистрированный пользователь** | Добавление своих методических материалов<br>Оценка материалов других пользователей<br>Скачивание и сохранение к себе в аккаунт |
| **Администратор**<br><sub>модератор</sub> | Проверка новых публикаций<br>Проверка пользователей |

---

##  В перспективе

Проект может развиться в **интеллектуальный архив**:

| Направление | Описание |
|:---|:---|
|  **Semantic Search** | поиск по смыслу, а не только по ключевым словам |
|  **OCR** | улучшенное распознавание осетинских документов |
|  **AI Assistant** | вопросы к архиву с указанием источников |
