# DzyrdLab

## Методический портал для хранения пособий и материалов по осетинскому языку.

Проект предназначен для учителей, воспитателей и родителей, дает пользователям удобное место, где методические разработки можно
найти по теме и классу, скачать, оценить и обсудить — а авторам — опубликовать
свою работу без бюрократии, но с возможностью рецензирования.

---

## Цель

Создать единое цифровое пространство, где материалы можно:

· загружать на платформу
· хранить и каталогизировать
· просматривать в цифровом виде
· скачивать на локальный носитель

---

## Первая версия проекта

В первую версию входят:
· Каталог материалов — структурированное хранилище всех записей
· Поиск и фильтрация — быстрый доступ к нужным документам
· Просмотр PDF и изображений — встроенная читалка прямо в браузере
· Административная панель — управление контентом и пользователями
· Скачивание файлов на устройство
· При публикации материалы отправляются на модерацию администраторам

В первой версии оставляем три базовые роли :
· Гость(без регистрации\входа) : просмотр всех разделов и материалов, поиск и фильтрация
· Зарегистрированный пользователь : добавление своих методических материалов, оценка материалов других пользователей, скачивание и сохранение к себе в аккаунт.
· Администратор(модератор) : проверка новых публикаций, проверка пользователей


---

## В перспективе

Проект может развиться в интеллектуальный архив:

· Semantic Search — поиск по смыслу, а не только по ключевым словам
· OCR — улучшенное распознавание осетинских документов
· AI Assistant — вопросы к архиву с указанием источников
